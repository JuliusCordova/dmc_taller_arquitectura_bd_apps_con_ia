# DMC Institute — Sesión 17

## Hardening avanzado, auditoría y validación de seguridad

**Duración:** 3 horas  
**Modalidad:** teórico-práctica  
**Programa:** Arquitectura y Bases de Datos con IA para Aplicaciones Modernas  
**Metodología:** Spec-Driven Development + framework ATLAS

## Pregunta guía

> Configuramos controles. ¿Cómo demostramos que realmente funcionan?

## Propósito

Evitar repetir la teoría de hardening y convertirla en evidencia. La sesión valida técnicamente red, roles, privilegios, TLS, secrets, extensiones, logs y auditoría; incorpora pruebas negativas y un hardening score didáctico para comparar el estado before/after.

## Resultado observable

Cada equipo termina con:

- security baseline validado;
- pruebas de exposición de red;
- revisión de permisos efectivos e inheritance;
- validación TLS;
- auditoría de secretos;
- auditoría de extensiones;
- evidencia de logs y actividad;
- hardening score before/after;
- matriz CIA actualizada;
- actualización de la DMC Application Specification.

## Idea fuerza

> Hardening no se demuestra con una configuración. Se demuestra con evidencia de que el control funciona.

## Conexión con la Sesión 18

La Sesión 17 demuestra la efectividad de los controles preventivos y detectivos. La Sesión 18 probará la capacidad de recuperación y operación ante fallas reales.
