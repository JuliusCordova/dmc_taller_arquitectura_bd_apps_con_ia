# Sesión 2

## De la visión del negocio a una Specification construible

**Tema:** Specification Engineering con IA.

Esta carpeta es la fuente de verdad de la Sesión 2 del programa **Arquitectura y Bases de Datos para Apps Modernas con IA**.

## Resultado central

Cada equipo transforma entrevistas y visión de producto en una primera versión verificable de la **DMC Application Specification v0.1**.

## Flujo metodológico

Entrevistas → Evidencias → Clasificación → Historias → Requisitos → Reglas → Criterios → Preguntas abiertas → Specification v0.1.

## Principio de la sesión

> La IA no debe comenzar escribiendo código. Primero debe ayudarnos a convertir conversaciones ambiguas en una especificación trazable, verificable y construible.
