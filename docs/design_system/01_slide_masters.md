# DMC Master Slide Library

Versión 1.0

## Objetivo
Establecer la biblioteca oficial de layouts reutilizables para todas las presentaciones académicas y ejecutivas de DMC Academy.

## Layouts canónicos

1. Hero Cover
2. Big Statement
3. Big Question
4. Agenda
5. Timeline
6. Before / After
7. Framework
8. Architecture
9. Process Flow
10. Demo
11. Workshop
12. Exercise
13. Case Study
14. Summary
15. Closing

## Reglas
- Una idea por diapositiva.
- Fondo blanco.
- Logo oficial DMC.
- Paleta institucional.
- Componentes reutilizables.
- Storytelling obligatorio.

## Regla de oro
Si una diapositiva no puede construirse utilizando alguno de los layouts oficiales, primero se amplía el Design System y luego se crea el nuevo layout. Nunca al revés.
