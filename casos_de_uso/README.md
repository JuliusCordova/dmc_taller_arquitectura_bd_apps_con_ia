# Casos de uso del taller

Esta carpeta contiene tres empresas y casos de uso ficticios para el taller **Arquitectura y Bases de Datos para Apps Modernas con IA**.

El material parte deliberadamente de entrevistas de descubrimiento. Los participantes deberán transformar conversaciones de negocio en:

1. problema y objetivo de negocio;
2. actores y procesos;
3. requerimientos funcionales y no funcionales;
4. reglas de negocio;
5. entidades, relaciones y eventos;
6. decisiones de arquitectura;
7. una primera versión de la **DMC Application Specification**.

> Todos los nombres, cifras, situaciones y personas descritos son ficticios y se usan únicamente con fines académicos.

## Dinámica sugerida

Cada equipo selecciona un caso y realiza las siguientes actividades:

1. Lee las tres entrevistas sin diseñar todavía la solución.
2. Identifica hechos, supuestos, contradicciones y preguntas abiertas.
3. Redacta el problema de negocio en una sola frase.
4. Define el resultado esperado y tres métricas de éxito.
5. Extrae actores, historias de usuario y reglas de negocio.
6. Propone el modelo conceptual inicial de datos.
7. Identifica eventos relevantes y necesidades de integración.
8. Define los principales requerimientos no funcionales.
9. Registra las decisiones en el Spec antes de generar código.

## Regla del taller

La IA puede ayudar a descubrir, organizar y validar requerimientos, pero no debe inventar hechos faltantes. Toda inferencia debe registrarse como hipótesis o pregunta abierta.
