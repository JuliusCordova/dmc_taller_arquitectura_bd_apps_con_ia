### Estructura prevista

Cada industria contiene tres vistas principales:

1. **Experiencia de cliente:** captura guiada, estado y próximos pasos.
2. **Consola operativa:** métricas, bandeja priorizada, estados y SLA.
3. **Control y trazabilidad:** expediente 360, línea de tiempo, evidencias y controles.

## Regla de trazabilidad para el taller

Cada equipo deberá mantener la cadena:

`Entrevista → Problema → Historia de usuario → RF/RNF → Criterio de aceptación → Pantalla → Entidad o evento → Prueba → Evidencia`
